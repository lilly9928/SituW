You will be given ONE clause/premise from a logic problem.

Task:
Produce a "current situation model" for this clause as JSON, including:
(1) an EVENT representation indexed by five dimensions:
    time, location, cause, intention, protagonist
(2) entities mentioned (canonicalized)
(3) logical content as graph-ready assertions:
    atomic facts and/or implication rules
(4) disjunction handling as multiple alternatives (branching current models)

Hard rules:
1) Output JSON ONLY. No extra text.
2) Do NOT invent facts. Every evidence string must be an exact substring of the clause.
3) If the clause contains disjunction (or / either ... or), represent it as multiple alternatives.
   - If it explicitly allows "or both", include an alternative for (A AND B).
4) Use short canonical strings. Normalize by lowercasing and collapsing spaces only.
5) Facts are atomic: subject + predicate (+ optional object) with polarity true/false.
6) Rules are explicit conditionals/quantified constraints: antecedent facts -> consequent facts.
7) If a five-dimension value is not explicitly present, set it to null (do not guess).

- "All X are Y" => rule: (x has_property X) -> (x has_property Y) OR use predicate forms directly; keep consistent.

- "either A or B" => alternatives: [A], [B] only.
- "aware/unaware that <content>" => predicate "aware" with object "<content>" and polarity true/false.
